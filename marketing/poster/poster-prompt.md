## Notes

- Keep the exact brand hex codes in the prompt so results stay on-brand; most tools respect explicit hex values loosely, expect to do 1-2 regenerations.
- Ask for "no text" from the image model if it garbles headlines, then add the real headline back as a text layer in Figma/Canva over the generated background.
- Always regenerate/avoid photoreal human faces unless you have real, licensed customer photos — using AI-generated "customers" in testimonials can be misleading; prefer illustrated or abstract icon-based variants for compliance.
