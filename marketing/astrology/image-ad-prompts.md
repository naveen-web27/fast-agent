## Text tip

Image models often misspell Tamil letters. Best results:

1. Generate with the prompt as written (it asks for no text), then add the Tamil copy above in Canva/Figma using
   **Noto Sans Tamil** / **Mukta Malar** / **Catamaran** (bold).
2. If you want the model to write text, keep it to one short line and paste the exact Tamil in quotes;
   regenerate until every letter is correct before using.
