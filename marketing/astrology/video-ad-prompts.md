# Astrology ad videos — Thirumana Porutham & Jathagam (Tamil)

Prompts for Gemini (Veo). Veo makes ~8-second clips, so each ad is 3–4 clips joined in CapCut / InShot / Canva.
Generate in **9:16** for Reels/Shorts/WhatsApp Status and **16:9** for YouTube.

Tips:

- Veo can speak Tamil but pronunciation is not always clean. Safer: generate clips with **music and ambient sound
  only**, then record the Tamil voiceover yourself (or use a Tamil TTS) and add captions in the editor.
- Ask for "no subtitles, no on-screen text" — add Tamil captions in the editor so spelling is correct.
- Never show a real phone screen with fake app UI claims; use the real screen recording of
  `https://rightconnect.app/pages/thirumana-porutham.html` for the app-demo shot.
- Avoid "100% accurate" / "guaranteed" / fear claims about dosham.
